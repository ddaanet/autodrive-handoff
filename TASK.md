The sweep in `scripts/report-drive-failure.sh` appends a line to `.claude/autodrive.swept` for every transition file it removes, naming the removing session, state, owner, kind, age and cwd. Two driven clears failed with the sentinel gone and no failure file; the first ran on a stale `dist/plugin` copy that had no record code, which has since been synced with `just dogfood` and the session restarted. This clear is the first that can leave a trace, so if it fails again, read `.claude/autodrive.swept` before anything else: it names who removed the sentinel, and that settles what distinguishes a dead owner from a concurrent session for both the held and the armed sweeps. `inbox/brief-https-submodule-urls.md` arrived from another session and is untriaged.
